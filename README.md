## 📌 კოდის მნიშვნელოვანი ნაწილები

### 1️⃣ ლოგების დამუშავება
```python
log_pattern = re.compile(r"(\d+\.\d+\.\d+\.\d+) - - \[(.*?)\] \"(\w+) ")
```
ეს რეგულარული გამოსახულება (regex) ამოწმებს და ლოგ ფაილიდან ამოიღებს IP-მისამართებს, თარიღებსა და მოთხოვნების ტიპებს.

### 2️⃣ მონაცემების DataFrame-ში გადაყვანა
```python
df = pd.DataFrame(data, columns=["IP", "Timestamp", "Method"])
df["Timestamp"] = pd.to_datetime(df["Timestamp"], format="%Y-%m-%d %H:%M:%S%z")
```
ეს კოდი მონაცემებს აწყობს DataFrame-ის სახით და თარიღს გადაყავს სათანადო ფორმატში, რაც აადვილებს ანალიზს.

### 3️⃣ შეტევის დროის იდენტიფიცირება
```python
ddos_time = time_counts.idxmax()
ddos_count = time_counts.max()
print(f"Potential DDoS Attack Time: {ddos_time}, Requests: {ddos_count}")
```
ეს კოდი ადგენს იმ დროს, როდესაც მოთხოვნების რაოდენობა მაქსიმალურია, რაც სავარაუდო DDoS შეტევის დროს მიუთითებს.

### 4️⃣ ყველაზე აქტიური IP-მისამართების პოვნა
```python
top_ips = Counter(df["IP"]).most_common(5)
print("Top 5 Attacking IPs:", top_ips)
```
აქ ვადგენთ იმ IP-ებს, რომლებმაც ყველაზე მეტი მოთხოვნა გააგზავნეს, რაც DDoS შეტევის წყაროს ამოცნობაში გვეხმარება.

### 5️⃣ ვიზუალიზაცია
```python
plt.figure(figsize=(12, 6))
time_counts.plot()
plt.axvline(ddos_time, color='r', linestyle='--', label="Potential DDoS")
plt.title("Requests Over Time")
plt.xlabel("Time")
plt.ylabel("Request Count")
plt.legend()
plt.show()
```
ეს კოდი ქმნის გრაფიკს, სადაც ვხედავთ მოთხოვნების რაოდენობას დროში. წითელი ხაზით აღინიშნება პოტენციური შეტევის დრო.
